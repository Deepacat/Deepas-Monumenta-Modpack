Deepa's Monumenta Pack is a Performance, QOL and polish focused mod-pack for the Monumenta CTM-MMORPG Minecraft server (See [Monumenta Website](https://playmonumenta.com/))

The modpack includes many Monumenta specific mods like the Unofficial Monumenta mod, Monumenta Addons, Monumenta Item Dictionary, USBPlus, and several of vladomemes off-platform mods and forks for Monumenta.

Many other QOL mods and the best of performance mods are also included for a smooth and great feeling experience.

All of the mods required to use every feature of the official Monumenta resource pack are present, and properly configured to cause no graphical issues and have everything display and perform nicely.

Custom buttons and information prompts are added in certain interfaces for shortcuts to useful Monumenta tools, commands, and helpful information about the Modpack.

Resource packs and my own edits and fixes of hud/GUI elements are included for a immersive fantasy oriented interface.

The lite version of this modpack is more immersion and new player focused, giving just a base polished experience without extra bells and whistles such as extra interface elements or waypoints.

This pack would also serve as a nice base to edit, adding and removing resourcepacks, mods, configuring, or whatever else you'd like to do with it!

**Recommended ingame settings (ingame `/player settings`)**
- Gameplay/Combat Options
  - Ability hotbar > disabled
  - Inventory drink > enabled
- Technical Options
  - Spoof world names > enabled
  - Auto Abandon completed dungeons > disabled
- Trigger/Interactable Options
  - Block interactions > disabled (Prevents accidental ability casts with scythes, and opening unwanted interfaces in combat)
  - Offhand swapping > disabled
  - Offhand swapping in inventory > disabled (Both offhand keys can be annoying and cause accidental swaps, safer to swap offhand with mouse clicks)
